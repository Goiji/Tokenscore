# ⚡ TokenScore

เว็บไซต์ให้คะแนนเหรียญคริปโตด้วยอินดิเคเตอร์ทางเทคนิค + **AI วิเคราะห์แบบมุมมองนักลงทุนอาชีพ**
ไฟล์เดียวจบ (`index.html`) — ไม่มี dependency ภายนอก ไม่ต้องมีเซิร์ฟเวอร์

## ✨ ฟีเจอร์

- 📊 **Top 50 เหรียญ** ตาม Market Cap (ข้อมูลจริงจาก CoinGecko สาธารณะ)
- 🎯 **คะแนนเร็ว (Quick Score 0–100)** สำหรับทุกเหรียญจากข้อมูล 24ชม./7วัน/30วัน/สภาพคล่อง
- 📈 **คะแนนเต็ม (Full Score 0–100)** คำนวณจากอินดิเคเตอร์บนแท่ง 4 ชั่วโมงย้อนหลัง 30 วัน:
  - เทรนด์ (SMA20/50 + MACD) 25%
  - โมเมนตัม (RSI + ROC) 25%
  - ความเสี่ยง (ATR + ความผันผวน) 20%
  - วอลุ่ม (Volume Momentum) 15%
  - สภาพสุดโต่ง (Overbought/Oversold) 15%
- 📉 กราฟราคา + Bollinger Bands + RSI + MACD (วาดด้วย Canvas ล้วน ๆ)
- 🧠 **บทวิเคราะห์อัตโนมัติ** (rule-based) — ใช้ได้ทันทีไม่ต้องตั้งค่า
- 🤖 **AI วิเคราะห์แบบมือนักลงทุนอาชีพ** — ใช้คีย์ API ของคุณเอง (OpenAI / OpenRouter / Groq / Pollinations ฟรี)
  สรุปเป็น ภาพรวม, แนวโน้ม, แนวรับ/แนวต้าน, ความเสี่ยง, กลยุทธ์ (จุดเข้า/stop loss/แบ่งไม้), และคะแนนความน่าสนใจ
- 🇹🇭 แสดงผลเป็น USD หรือ THB

## 🔒 ความปลอดภัย (สำคัญมาก อ่านก่อน)

> **ไม่มี API key ใด ๆ ฝังอยู่ในโค้ดของไฟล์นี้** — คุณตรวจสอบซอร์สโค้ดได้ทุกบรรทัด

| มาตรการ | รายละเอียด |
|---|---|
| 🔑 เข้ารหัสคีย์ | คีย์ AI ถูกเข้ารหัส **AES-256-GCM** ด้วยรหัส PIN ของคุณ (PBKDF2 210,000 รอบ) และเก็บใน localStorage ของเบราว์เซอร์เครื่องคุณเท่านั้น |
| 🔐 ล็อกหน้าจอ | เปิดเว็บต้องกรอก PIN ก่อน ใครอื่นที่เปิด URL เดียวกันจะเห็นแค่หน้าล็อก — เข้าไม่ได้และอ่านคีย์ไม่ออก |
| 🚫 ไม่มีคีย์ในโค้ด | คนที่ดูโค้ดบน GitHub เห็นแค่ช่องกรอกคีย์เปล่า ๆ ไม่มีคีย์ของคุณ |
| 🛡️ บังคับ HTTPS | ถ้าเปิดผ่าน HTTP (ไม่ปลอดภัย) ระบบจะปิดการเรียก AI อัตโนมัติ เพื่อกันคีย์ถูกดักฟัง |
| ⏱️ จำกัดการใช้งาน | จำกัดการเรียก AI 12 ครั้ง/ชั่วโมง กันคีย์ถูกใช้เกินงบ |
| ✋ CSP + sanitize | Content-Security-Policy แบบเข้มงวด + escape ข้อมูลทุกตัวก่อนแสดง (กัน XSS) |
| ⏳ ล็อกอัตโนมัติ | ล็อกหน้าจอเองเมื่อไม่ใช้งาน 15 นาที (เปิด/ปิดได้ในตั้งค่า) |

ข้อควรรู้: การเรียก AI เกิดจากเบราว์เซอร์ของคุณตรงไปยังผู้ให้บริการที่คุณเลือก
(ไม่มี proxy กลาง) — คีย์จะถูกส่งเฉพาะไปยังเว็บผู้ให้บริการเจ้าของคีย์เท่านั้น

## 🚀 วิธีใช้งาน

### เปิดใช้บน GitHub Pages (ฟรี)

1. Push repo นี้ไปที่ GitHub ของคุณ
2. เข้า repo → **Settings → Pages**
3. เลือก Source เป็น **Deploy from a branch** → branch `main` → folder `/ (root)` → Save
4. รอ 1–2 นาที แล้วเปิด `https://<username>.github.io/Tokenscore/`
5. ตั้งค่า PIN + ใส่คีย์ AI ของคุณ (หรือเลือก **Pollinations** เพื่อทดลองฟรีไม่ต้องมีคีย์)

### เปิดใช้บนเครื่องตัวเอง

- เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ใช้ `file://` ได้
  แต่ระบบจะปิดการเรียก AI เพราะไม่ใช่ HTTPS)
- วิธีที่แนะนำ: รัน `python3 -m http.server 8080` แล้วเปิด
  `http://localhost:8080` — ระบบอนุญาต AI บน localhost

### ตั้งค่า AI (ขั้นตอนในเว็บ)

| ผู้ให้บริการ | เอา Base URL / Model มาจากไหน | คีย์ |
|---|---|---|
| **OpenAI** | `https://api.openai.com/v1` • `gpt-4o-mini` | platform.openai.com → API keys |
| **OpenRouter** | `https://openrouter.ai/api/v1` • `deepseek/deepseek-chat` | openrouter.ai → Keys |
| **Groq** | `https://api.groq.com/openai/v1` • `llama-3.3-70b-versatile` | console.groq.com → API Keys |
| **Pollinations** | ฟรี ไม่ต้องใช้คีย์ (เหมาะลองเล่น) | — |
| **กำหนดเอง** | OpenAI-compatible endpoint ใดก็ได้ | แล้วแต่บริการ |

> ⚠️ อย่ากรอกคีย์จากเว็บปลอม — ใช้เฉพาะเว็บทางการของผู้ให้บริการเท่านั้น
