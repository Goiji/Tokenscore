# ⚡ TokenScore

เว็บไซต์สแกนหา **เหรียญที่น่าจับตา (Watchlist)** ราคายังไม่พุ่ง + ให้คะแนนด้วยอินดิเคเตอร์ทางเทคนิค (RSI, MACD, Bollinger Squeeze) + **AI วิเคราะห์แบบมุมมองนักลงทุนสถาบัน (เชิงการศึกษา)**
ไฟล์เดียวจบ (`index.html`) — ไม่มี dependency ภายนอก ไม่ต้องมีเซิร์ฟเวอร์ เปิดใช้ได้ทันที ฟรี

---

## ✨ ฟีเจอร์หลัก (Features)

### 🎯 1. เรดาร์เหรียญที่น่าจับตา (Watchlist Radar)
- **สแกนจับเหรียญที่ราคายังไม่พุ่ง:** คัดกรองเหรียญที่กำลังสร้างฐานสะสมพลัง (Consolidation Base) ป้องกันความเสี่ยงจากการไล่ราคา (FOMO)
- **คะแนนน่าจับตา (Watchlist Score 0–100):** คำนวณความน่าสนใจจาก 5 มิติ:
  1. *Unpumped Price (30%):* 24ชม. และ 7วัน ราคายังพักตัว ไม่หลุดดอย ไม่ใช่ยอดดอย
  2. *RSI Sweet Spot (25%):* RSI อยู่ในโซนสะสม (30–50) หรือ Oversold Reversal ไม่อยู่ในโซน Overbought (>70)
  3. *MACD Momentum Shift (20%):* MACD Histogram กำลังวกตัวขึ้น / เกิด Golden Cross
  4. *Bollinger Bands Squeeze (15%):* ตรวจจับการบีบตัวของความผันผวน (Volatility Compression) จ่อระเบิดทิศทางใหม่
  5. *Accumulation & Support (10%):* วอลุ่มหนุนและราคาเกาะแนวรับ
- **Hero Spotlight Top 3 Picks:** ไฮไลต์ 3 เหรียญที่น่าจับตามากที่สุดประจำรอบ พร้อมเหตุผลสรุป

### 📦 2. โหมดเพิ่งเริ่มสะสมพลัง 30 วัน (30-Day Accumulation Base)
- **คัดกรองเหรียญที่สร้างฐาน 30 วัน:** เปลี่ยนแปลง 30 วันอยู่ในกรอบ **-22% ถึง +15%** — ผ่านด่าน "ไม่ไล่ยอดดอย และไม่หลุดโครงสร้าง"
- **ราคาอยู่โซนล่าง 15%–48% ของกรอบ 30 วัน:** ใกล้แนวรับ มี Room ให้วิ่งกลับสู่ High 30 วัน
- **24ชม./7วัน เพิ่งเริ่มยก Low (+0.2% ถึง +4.5%):** จับจังหวะ "แรงซื้อเพิ่งกลับมา" แบบนุ่ม ๆ — ไม่ใช่การไล่ยอดดอย
- **คะแนนสะสมพลัง 30 วัน (Accumulation Score 0–100)** จาก 4 มิติ:
  1. *โครงสร้างฐาน 30 วัน (30%)* — กรอบ -22% ถึง +15% (หวานสุด -12% ถึง +8%)
  2. *ตำแหน่งในกรอบ (30%)* — โซนล่าง 15–48% จาก Low 30 วัน
  3. *การเริ่มยก Low (25%)* — 24ชม./7วัน ในหน้าต่าง +0.2% ถึง +4.5%
  4. *คุณภาพโครงสร้าง (15%)* — Higher Lows + ฐานแนวนอน (ความผันผวน 14 วันต่ำ)
- **คอลัมน์ + แถบ "ตำแหน่งในกรอบ 30ว":** แสดง % จาก Low 30 วัน (เช่น 32% จาก Low 30ว) พร้อมแถบโซนสี (แดง <15% / เขียว 15–48% / เหลือง >48%) เรียงลำดับได้
- **Spotlight Top 3 เหรียญสะสมพลัง 30 วัน** หน้าแรก พร้อมแถบตำแหน่งในกรอบและเหตุผลสรุป
- **Checklist โครงสร้าง 30 วัน + แผนเทรด (Entry / SL / TP1 / TP2 + R:R)** ในหน้าต่างเจาะลึก (Drawer): SL อิงแนวรับฐาน (ต่ำกว่า Low 7 วัน − 0.8 ATR), TP2 ชี้เป้า High 30 วัน
- หมายเหตุ: ข้อมูล OHLC 30 วันดึงจาก CoinGecko **ทีละเหรียญแบบ Progressive** — CoinGecko สาธารณะจำกัดประมาณ 5-15 คำขอ/นาที ระบบจึงเว้นจังหวะอัตโนมัติ (ช้าลงเมื่อเจอ rate limit / เร็วขึ้นเมื่อลื่น) + retry เหรียญที่โดนปฏิเสธ + โหลดเหรียญที่ผู้ใช้กำลังดูก่อน — ครบทุกเหรียญใน ~3-6 นาที และ**เก็บไว้ในเครื่อง 45 นาที** (เปิดหน้าใหม่แสดงได้ทันทีโดยไม่ต้องโหลดซ้ำ)

### 📈 3. กราฟราคาความละเอียดสูงในตาราง (High-Definition Sparkline)
- ปุ่มสลับมุมมอง **[ 📈 กราฟ 7 วัน | 📈 กราฟ 30 วัน ]** ในแถบเครื่องมือ
- แสดง**กราฟราคาจริง** (เส้น + Area Gradient) พร้อม **จุดราคาเริ่มต้น** 📍, จุด Min (ฟ้า) / Max (เหลือง) และ **จุดไฟกระพริบที่ราคาล่าสุด** ✨
- **Tooltip เมื่อชี้กราฟ:** ราคาเริ่มต้น / ต่ำสุด (Min) / สูงสุด (Max) / % เปลี่ยนแปลงของช่วง
- คลิกหัวคอลัมน์เทรนด์เพื่อเรียงตาม % เปลี่ยนแปลงของกราฟที่แสดงอยู่

### 📊 4. โหมดสแกนเนอร์และตัวกรองอัจฉริยะ (Smart Scanners)
- 🎯 **เหรียญน่าจับตา (Watchlist)**: ดูเฉพาะเหรียญที่สะสมพลังและน่าจับตา
- 📦 **เพิ่งเริ่มสะสมพลัง 30 วัน**: ฐาน 30 วันเสร็จ + ราคาโซนล่าง + เพิ่งเริ่มยก Low
- 🗜️ **BB Squeeze จ่อระเบิด**: คัดเฉพาะเหรียญที่กรอบ Bollinger บีบตัวต่ำสุดในรอบ 7 วัน
- 🔄 **MACD กำลังกลับตัว**: คัดเหรียญที่แรงขายเริ่มหดตัวและจ่อตัดขึ้น
- 📉 **RSI โซนรับของถูก (Oversold Dip)**: คัดเหรียญ RSI ต่ำที่เด้งรับแนวรับ
- 🔥 **โมเมนตัมนำตลาด (Top Momentum)**: สำหรับสายเทรดตามเทรนด์
- 🛡️ **ตัวกรองอัจฉริยะ:** ปุ่มสลับ "ซ่อนเหรียญที่พุ่งแล้ว (>10%)", "ซ่อน Stablecoin / Pegged"

### 📈 5. การประเมินแผนเทรด & กรอบราคาเชิงกลยุทธ์ (Trade Setup)
- 🟢 **โซนเข้าสะสม (Entry Zone)**
- 🔴 **จุด Stop Loss อ้างอิง** (คำนวณจากแนวรับ Bollinger ล่าง และ ATR)
- 🎯 **เป้าหมายกำไร (Take Profit 1 & 2)**
- ⚖️ **อัตราส่วน Risk / Reward (R:R Ratio)**

### 🤖 6. AI วิเคราะห์แบบมือนักลงทุนอาชีพ
- วิเคราะห์ว่าเหรียญอยู่ในช่วง **"สะสมพลัง"** หรือ **"วิ่งไปแล้ว/Overbought"** (รวมข้อมูลโครงสร้างฐาน 30 วัน และคะแนนสะสมพลัง)
- แนวทาง Position Sizing และการแบ่งไม้ (เชิงการศึกษา)
- ใช้งาน **AI ฟรี (Pollinations)** ได้ทันที ไม่ต้องมีคีย์ หรือใส่คีย์ OpenAI / OpenRouter / Groq ส่วนตัวที่เข้ารหัส AES-256 ในเครื่อง

## 🧑‍💻 พัฒนาและทดสอบ

- เปิด `index.html` ได้โดยตรง หรือรัน `python3 -m http.server 8080` → `http://localhost:8080`
- ตรรกะการคำนวณทั้งหมดเป็น pure functions (`window.TS`) ทดสอบได้โดยไม่ต้องเปิดเบราว์เซอร์
- Pure functions ที่สำคัญ: `analyzeSparkline`, `acc30Metrics`, `acc30Score` (คะแนนสะสมพลัง 30 วัน), `computeScore`, `sparkHD` (HD Sparkline), `frameBarHTML` (แถบตำแหน่งในกรอบ 30 วัน)

### 🔄 รอบการอัปเดตข้อมูล (Data Refresh Policy)
- **อัปเดตอัตโนมัติทุก 2 ชั่วโมง** หลังโหลดสำเร็จล่าสุด (ลดโอกาสโดน rate limit ของ CoinGecko สาธารณะ)
- **โหลดไม่สำเร็จ (เช่น rate limit / เน็ตหลุด):** ระบบ**คงข้อมูลชุดล่าสุดที่โหลดสำเร็จไว้บนหน้าจอ** พร้อม banner บอกเวลาอัปเดตล่าสุด + ปุ่ม "ลองใหม่ตอนนี้" และจะลองใหม่เองในอีก 15 นาที
- **ยังไม่เคยโหลดสำเร็จเลย:** ลองใหม่ทุก 90 วินาทีจนกว่าจะได้ข้อมูล
- **ข้อมูลสำรองในเครื่อง (localStorage):** ชุดข้อมูลล่าสุดที่โหลดสำเร็จถูกเก็บไว้ในเบราว์เซอร์ของคุณ — เปิดหน้าใหม่ตอน API ล่มก็ยังมีข้อมูลให้ดู และลบได้ตลอดจากปุ่ม "ล้างข้อมูลทั้งหมดในเครื่องนี้"

### 🛰️ แหล่งข้อมูลสำรอง 3 ชั้น (Auto Failover)

เมื่อ CoinGecko (แหล่งหลัก) ล่มหรือโดน rate limit ระบบจะ**สลับไปใช้แหล่งสำรองเองอัตโนมัติ** โดยผู้ใช้ไม่ต้องกดอะไร และจะสลับกลับ CoinGecko เองเมื่อแหล่งหลักกลับมาปกติในรอบถัดไป:

| ชั้น | แหล่งข้อมูล | ต้องตั้งค่า? | ข้อมูลที่ได้ |
|---|---|---|---|
| 1️⃣ หลัก | CoinGecko | ไม่ต้อง | ครบทุกอย่าง รวมข้อมูล OHLC 30 วันสำหรับคะแนนสะสมพลัง |
| 2️⃣ สำรอง | CoinMarketCap (ผ่าน Netlify Function) | ต้อง deploy บน Netlify + ตั้ง `CMC_API_KEY` | ราคา / วอลุ่ม / Market Cap / อันดับ (กราฟย่อย 7 วันใช้ชุดล่าสุดที่มีจาก CoinGecko) |
| 3️⃣ สุดท้าย | Binance (Public Market Data) | ไม่ต้อง | ราคา / วอลุ่ม / กราฟ 7 วัน / % 7 วัน–30 วัน (ไม่มี Market Cap / อันดับ) |

- ตรวจสอบสถานะแต่ละชั้นได้ที่ **⚙️ ตั้งค่า → แหล่งข้อมูลตลาด → ปุ่ม "ทดสอบการเชื่อมต่อ"**
- โหมดที่ใช้แหล่งสำรอง จะ**ไม่คำนวณคะแนนสะสมพลัง 30 วัน**ชั่วคราว (ข้อมูล OHLC รายวัน 30 วันมีเฉพาะ CoinGecko) — จะกลับมาคำนวณเองเมื่อกลับไปใช้แหล่งหลัก
- อัตราแลกเปลี่ยน THB ก็มีสำรองเช่นกัน: CoinGecko → Binance (BTCTHB/BTCUSDT)

**เปิดใช้ชั้น CoinMarketCap (เฉพาะผู้ deploy บน Netlify):**

> CoinMarketCap บล็อกการเรียก API จากเบราว์เซอร์โดยตรง (CORS) เพื่อปกป้อง API key — จึงต้องมี Netlify Function เป็นตัวกลาง (`netlify/functions/cmc.js` มีใน repo แล้ว whitelist เฉพาะ endpoint ที่จำเป็น)

1. สมัครคีย์ฟรี (Basic 10,000 credits/เดือน) ที่ [coinmarketcap.com/api](https://coinmarketcap.com/api)
2. Deploy repo นี้บน Netlify ("Add new site → Import an existing project" — `netlify.toml` ตั้งค่า functions ให้อัตโนมัติ)
3. **Site configuration → Environment variables → Add a variable** → key: `CMC_API_KEY` → value: คีย์ของคุณ
4. **Deploys → Trigger deploy → Clear cache and deploy site** เพื่อให้ตัวแปรใหม่มีผล
5. เปิดเว็บ → ⚙️ ตั้งค่า → กด "ทดสอบการเชื่อมต่อ" → ควรเห็น "CoinMarketCap: ✓ proxy พร้อมใช้"

- Deploy ที่ไหนไม่ใช่ Netlify (เช่น GitHub Pages) จะไม่มีชั้น CMC — ระบบจะข้ามไป Binance ให้เอง (ยังมีข้อมูลสำรองใช้เสมอ)
- คีย์ `CMC_API_KEY` อยู่ที่ Environment ของ Netlify เท่านั้น ไม่ถูกส่งถึงหรือเก็บในเบราว์เซอร์ของผู้ใช้
- Function มีแคช 60 วินาที + จำกัดอัตราการเรียกต่อ IP เพื่อไม่ให้ credits หมดเร็ว
