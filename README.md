# ⚡ TokenScore

เว็บไซต์สแกนหา **เหรียญต้นน้ำ (Early Buy Setup)** ราคายังไม่พุ่ง + ให้คะแนนด้วยอินดิเคเตอร์ทางเทคนิค (RSI, MACD, Bollinger Squeeze) + **AI วางแผนเทรดแบบมุมมองนักลงทุนสถาบัน**
ไฟล์เดียวจบ (`index.html`) — ไม่มี dependency ภายนอก ไม่ต้องมีเซิร์ฟเวอร์ เปิดใช้ได้ทันที ฟรี

---

## ✨ ฟีเจอร์หลัก (Features)

### 🎯 1. เรดาร์เหรียญต้นน้ำ (Early Buy / Pre-Pump Radar)
- **สแกนจับเหรียญที่ราคายังไม่พุ่ง:** คัดกรองเหรียญที่กำลังสร้างฐานสะสมพลัง (Consolidation Base) ป้องกันความเสี่ยงจากการไล่ราคา (FOMO)
- **คะแนนต้นน้ำ (Early Buy Score 0–100):** คำนวณความน่าสนใจจาก 5 มิติ:
  1. *Unpumped Price (30%):* 24ชม. และ 7วัน ราคายังพักตัว ไม่หลุดดอย ไม่ใช่ยอดดอย
  2. *RSI Sweet Spot (25%):* RSI อยู่ในโซนสะสม (30–50) หรือ Oversold Reversal ไม่อยู่ในโซน Overbought (>70)
  3. *MACD Momentum Shift (20%):* MACD Histogram กำลังวกตัวขึ้น / เกิด Golden Cross
  4. *Bollinger Bands Squeeze (15%):* ตรวจจับการบีบตัวของความผันผวน (Volatility Compression) จ่อระเบิดทิศทางใหม่
  5. *Accumulation & Support (10%):* วอลุ่มหนุนและราคาเกาะแนวรับ
- **Hero Spotlight Top 3 Picks:** ไฮไลต์ 3 เหรียญต้นน้ำที่จังหวะเข้าซื้อดีที่สุดประจำรอบ พร้อมเหตุผลสรุป

### 📊 2. โหมดสแกนเนอร์และตัวกรองอัจฉริยะ (Smart Scanners)
- 🎯 **เหรียญต้นน้ำ (Early Buy)**: ดูเฉพาะเหรียญที่สะสมพลัง จังหวะเข้าซื้อได้เปรียบ
- 🗜️ **BB Squeeze จ่อระเบิด**: คัดเฉพาะเหรียญที่กรอบ Bollinger บีบตัวต่ำสุดในรอบ 7 วัน
- 🔄 **MACD กำลังกลับตัว**: คัดเหรียญที่แรงขายเริ่มหดตัวและจ่อตัดขึ้น
- 📉 **RSI โซนรับของถูก (Oversold Dip)**: คัดเหรียญ RSI ต่ำที่เด้งรับแนวรับ
- 🔥 **โมเมนตัมนำตลาด (Top Momentum)**: สำหรับสายเทรดตามเทรนด์
- 🛡️ **ตัวกรองอัจฉริยะ:** ปุ่มสลับ "ซ่อนเหรียญที่พุ่งแล้ว (>10%)", "ซ่อน Stablecoin / Pegged"

### 📈 3. การประเมินแผนเทรด & กรอบราคาเชิงกลยุทธ์ (Trade Setup)
- 🟢 **โซนเข้าสะสม (Entry Zone)**
- 🔴 **จุด Stop Loss แนะนำ** (คำนวณจากแนวรับ Bollinger ล่าง และ ATR)
- 🎯 **เป้าหมายกำไร (Take Profit 1 & 2)**
- ⚖️ **อัตราส่วน Risk / Reward (R:R Ratio)**

### 🤖 4. AI วิเคราะห์แบบมือนักลงทุนอาชีพ
- วิเคราะห์ว่าเหรียญอยู่ในช่วง **"ต้นน้ำ/สะสมพลัง"** หรือ **"วิ่งไปแล้ว/Overbought"**
- แนะนำ Position Sizing และกลยุทธ์การแบ่งไม้
- ใช้งาน **AI ฟรี (Pollinations)** ได้ทันที ไม่ต้องมีคีย์ หรือใส่คีย์ OpenAI / OpenRouter / Groq ส่วนตัวที่เข้ารหัส AES-256 ในเครื่อง

## 🚀 เปิดใช้บนเว็บสาธารณะ (GitHub Pages — ฟรี)

1. Push repo นี้ไปที่ GitHub ของคุณ
2. เข้า repo → **Settings → Pages**
3. Source: **Deploy from a branch** → branch `main` → folder `/ (root)` → Save
4. รอ 1–2 นาที แล้วเปิด `https://<username>.github.io/Tokenscore/` — ทุกคนเข้าใช้ได้ทันที

## 🔒 ความปลอดภัยของคีย์ (สำคัญ)

> **ไฟล์นี้ไม่มี API key ใด ๆ ฝังอยู่ในโค้ด และไม่มี proxy กลาง** — คุณตรวจสอบซอร์สโค้ดได้ทุกบรรทัด

| มาตรการ | รายละเอียด |
|---|---|
| 🔑 เข้ารหัสคีย์ของผู้ใช้ | เมื่อผู้ใช้กรอกคีย์ของตัวเอง คีย์จะถูกเข้ารหัส **AES-256-GCM** (PBKDF2 210,000 รอบ) ด้วย PIN ส่วนตัวของผู้ใช้คนนั้น และเก็บใน localStorage ของเบราว์เซอร์เครื่องของเขาเท่านั้น |
| 🚫 เจ้าของเว็บแตะคีย์ไม่ได้ | คีย์ถูกส่งตรงจากเบราว์เซอร์ของผู้ใช้ไปยังผู้ให้บริการเจ้าของคีย์เท่านั้น (OpenAI/OpenRouter/Groq) — ไม่ผ่านเซิร์ฟเวอร์กลาง |
| 🛡️ บังคับ HTTPS | เปิดผ่าน HTTP จะปิดการเรียก AI อัตโนมัติ กันคีย์ถูกดักฟัง |
| ⏱️ จำกัดการใช้งาน | AI ฟรี 20 ครั้ง/ชม./ผู้ใช้; โหมดคีย์ส่วนตัว 12 ครั้ง/ชม. กันคีย์ถูกใช้เกินงบ |
| ✋ CSP + sanitize | Content-Security-Policy เข้มงวด + escape ข้อมูลทุกตัวก่อนแสดง (กัน XSS) |
