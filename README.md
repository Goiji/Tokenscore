# ⚡ TokenScore

เว็บไซต์ให้คะแนนเหรียญคริปโตด้วยอินดิเคเตอร์ทางเทคนิค + **AI วิเคราะห์แบบมุมมองนักลงทุนอาชีพ**
ไฟล์เดียวจบ (`index.html`) — ไม่มี dependency ภายนอก ไม่ต้องมีเซิร์ฟเวอร์ เปิดใช้ได้ทันที ฟรี

## ✨ ฟีเจอร์

- 📊 **Top 50 เหรียญ** ตาม Market Cap (ข้อมูลจริงจาก CoinGecko สาธารณะ)
- 🎯 **คะแนนเร็ว (Quick Score 0–100)** สำหรับทุกเหรียญจากข้อมูล 24ชม./7วัน/30วัน/สภาพคล่อง
- 📈 **คะแนนเต็ม (Full Score 0–100)** คำนวณจากอินดิเคเตอร์บนแท่ง 4 ชั่วโมงย้อนหลัง 30 วัน:
  - เทรนด์ (SMA20/50 + MACD) 25%
  - โมเมนตัม (RSI + ROC) 25%
  - ความเสี่ยง (ATR + ความผันผวน) 20%
  - วอลุ่ม (Volume Momentum) 15%
  - สภาพสุดโต่ง (Overbought/Oversold) 15%
- 📉 กราฟราคา + Bollinger Bands + RSI + MACD (วาดด้วย Canvas ล้วน ๆ)
- 🧠 **บทวิเคราะห์อัตโนมัติ** (rule-based) — ใช้ได้ทันทีไม่ต้องตั้งค่า
- 🤖 **AI วิเคราะห์แบบมือนักลงทุนอาชีพ** — สรุป ภาพรวม, แนวโน้ม, แนวรับ/แนวต้าน, ความเสี่ยง,
  กลยุทธ์ (จุดเข้า/stop loss/แบ่งไม้), และคะแนนความน่าสนใจ
- 🇹🇭 แสดงผลเป็น USD หรือ THB, อัปเดตอัตโนมัติ 90 วินาที

## 🚀 เปิดใช้บนเว็บสาธารณะ (GitHub Pages — ฟรี)

1. Push repo นี้ไปที่ GitHub ของคุณ
2. เข้า repo → **Settings → Pages**
3. Source: **Deploy from a branch** → branch `main` → folder `/ (root)` → Save
4. รอ 1–2 นาที แล้วเปิด `https://<username>.github.io/Tokenscore/` — ทุกคนเข้าใช้ได้ทันที

## 🤖 AI: ใครใช้อย่างไร

| ผู้ใช้ | การทำงาน |
|---|---|
| **ผู้ใช้ทั่วไป** | ใช้ **AI ฟรี (Pollinations)** ได้ทันที ไม่ต้องสมัคร ไม่ต้องมีคีย์ (จำกัด 20 ครั้ง/ชม. ต่อผู้ใช้ — ความเร็ว/ความพร้อมขึ้นอยู่กับผู้ให้บริการฟรี) |
| **ผู้ใช้ที่มีคีย์ของตัวเอง** | ใส่คีย์ใน ⚙️ ตั้งค่า (OpenAI / OpenRouter / Groq / OpenAI-compatible อื่น ๆ) เพื่อความเร็วและความเสถียรที่ดีกว่า |

## 🔒 ความปลอดภัยของคีย์ (สำคัญ — อ่านก่อนอัปเว็บ)

> **ไฟล์นี้ไม่มี API key ใด ๆ ฝังอยู่ในโค้ด และไม่มี proxy กลาง** —
> คุณตรวจสอบซอร์สโค้ดได้ทุกบรรทัด

| มาตรการ | รายละเอียด |
|---|---|
| 🔑 เข้ารหัสคีย์ของผู้ใช้ | เมื่อผู้ใช้กรอกคีย์ของตัวเอง คีย์จะถูกเข้ารหัส **AES-256-GCM** (PBKDF2 210,000 รอบ) ด้วย PIN ส่วนตัวของผู้ใช้คนนั้น และเก็บใน localStorage ของเบราว์เซอร์เครื่องของเขาเท่านั้น |
| 🚫 เจ้าของเว็บแตะคีย์ไม่ได้ | คีย์ถูกส่งตรงจากเบราว์เซอร์ของผู้ใช้ไปยังผู้ให้บริการเจ้าของคีย์เท่านั้น (OpenAI/OpenRouter/Groq) — ไม่ผ่านเว็บของคุณ ไม่ถูกส่งมาให้คุณ |
| 🛡️ บังคับ HTTPS | เปิดผ่าน HTTP จะปิดการเรียก AI อัตโนมัติ กันคีย์ถูกดักฟัง |
| ⏱️ จำกัดการใช้งาน | AI ฟรี 20 ครั้ง/ชม./ผู้ใช้; โหมดคีย์ส่วนตัว 12 ครั้ง/ชม. กันคีย์ถูกใช้เกินงบ |
| ✋ CSP + sanitize | Content-Security-Policy เข้มงวด + escape ข้อมูลทุกตัวก่อนแสดง (กัน XSS) |

### ⚠️ สิ่งที่ไม่ควรทำ (จะทำคีย์รั่วทันที)

- ❌ **อย่า** นำคีย์ API ส่วนตัวของคุณไปใส่ในโค้ดแล้วอัป GitHub — ทุกคนที่กด F12 จะเห็นคีย์และนำไปใช้ได้
- ❌ อย่าคอมมิตคีย์ลง repo, อย่าเขียนคีย์ใน README/issue/commit message
- ✅ วิธีที่ถูกต้องคือสิ่งที่เว็บนี้ทำอยู่แล้ว: เปิดช่องให้ผู้ใช้**แต่ละคน**กรอกคีย์ของตัวเอง ซึ่งถูกเข้ารหัสไว้ในเครื่องของเขา

## 🧑‍💻 พัฒนา/ทดสอบ

- เปิด `index.html` ได้โดยตรง หรือ `python3 -m http.server 8080` → `http://localhost:8080`
- ตรรกะการคำนวณทั้งหมดเป็น pure functions (`window.TS`) แยกส่วนจาก UI — ทดสอบได้โดยไม่ต้องเปิดเบราว์เซอร์
